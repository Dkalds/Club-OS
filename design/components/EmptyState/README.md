# EmptyState

Lo que se ve cuando una lista o pantalla no tiene contenido todavía.

**Qué aporta quien lo usa:** icono, título (qué falta, en 3–4 palabras), una frase que explica qué hacer y la acción que lo resuelve.

- Siempre con una salida: crear, quitar filtros o volver.
- Tono directo y útil; sin ilustraciones ni humor.
