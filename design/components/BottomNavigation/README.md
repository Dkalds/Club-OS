# BottomNavigation

La navegación principal móvil: Inicio, The Way, Entrenar, Partidos, Equipo.

**Qué aporta quien lo usa:** la pestaña activa. Las etiquetas vienen de la terminología del club (`organization_branding.terminology`): «The Way» puede llamarse distinto en otro club.

- Altura `nav-height` + área segura del dispositivo; fondo `surface-1`, línea superior `line`.
- Activa: icono y etiqueta `brand-accent`, trazo más grueso, `aria-current="page"`. Inactivas: `ink-3`.
- Siempre cinco pestañas con icono + texto; nunca solo iconos.
- Se oculta en el Live Mode y en el Practice Builder a pantalla completa.
