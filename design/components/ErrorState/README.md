# ErrorState

Un fallo que impide mostrar el contenido.

**Qué aporta quien lo usa:** qué no se pudo hacer, la causa probable en lenguaje llano, si se ha perdido algo y la acción de reintento.

- Icono en `danger` sobre `danger-soft`, siempre con texto: el color no basta.
- Nunca códigos técnicos ni datos de otros usuarios en el mensaje.
- Errores de permiso: «No tienes acceso a esta sección», sin revelar si el recurso existe.
