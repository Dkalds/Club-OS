# Avatar

Representa a una persona o a un equipo cuando no hay foto, o cuando no debe haberla.

**Qué aporta quien lo usa:** nombre (para las iniciales y la etiqueta accesible), tamaño (`sm` 32, `md` 40, `lg` 64) y, solo con consentimiento de imagen, la URL firmada de la foto.

- Por defecto, iniciales en `ink` sobre `surface-2`. Variante `number`: dorsal en `brand-accent`.
- Foto: en blanco y negro, recortada en círculo. Sin consentimiento registrado no se pide ni se muestra.
