# SectionHeader

Título de un bloque de contenido dentro de una pantalla, con una acción opcional.

**Qué aporta quien lo usa:** el título (estilo `title`, mayúsculas, 1–3 palabras) y, opcionalmente, un enlace de acción en `brand-accent` («Ver todo», «Calendario»).

- Separación `space-6` por encima y `space-3` por debajo.
- Una sola acción como máximo; si hay más, van dentro del contenido.
