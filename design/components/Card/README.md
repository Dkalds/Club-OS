# Card

El contenedor base: agrupa un tema en una superficie.

**Qué aporta quien lo usa:** el contenido; elige la variante.

- `default`: `surface-1`, borde `line`, radio `radius-lg`, padding `space-4`.
- `spotlight`: fondo `spotlight` (blanco roto), texto `on-spotlight`, radio `radius-xl`. **Máximo una por pantalla**, para la información más importante de hoy.
- `flush`: sin padding, para listas de filas (`ListRow`, `PlayerCard`, `DrillCard`).
- Sin sombras ni bordes de color a un lado. Separación entre cards `space-3`; entre secciones `space-6`.
