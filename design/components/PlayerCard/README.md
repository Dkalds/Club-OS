# PlayerCard

Un jugador en la plantilla de un equipo.

**Qué aporta quien lo usa:** dorsal, nombre, posición y la foto solo si el jugador tiene consentimiento de imagen registrado; si no, iniciales.

- Dorsal en `brand-accent`, `font-display`, alineado a la derecha para que la columna se lea de un vistazo.
- Orden por dorsal. Toda la fila lleva a la ficha del jugador.
- Nunca mostrar fecha de nacimiento, contacto ni notas en la fila.
